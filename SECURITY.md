# Security Policy

## Supported Versions

Security fixes are provided for the latest major release line only.

| Version | Supported |
| ------- | --------- |
| 2.x     | ✅        |
| 1.x     | ❌        |
| < 1.0   | ❌        |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub
issues, discussions, or pull requests.**

Instead, use one of these private channels:

- **GitHub Private Vulnerability Reporting** — open an advisory via the
  ["Report a vulnerability"](https://github.com/RuedigerVoigt/bote/security/advisories/new)
  button on the repository's *Security* tab (preferred).
- **Email** — send a report to `projects@ruediger-voigt.eu`.

Please include enough detail to reproduce the issue: the affected version,
a description of the vulnerability and its impact, and step-by-step
instructions or a proof of concept where possible.

## What to Expect

- Acknowledgement of your report within **14 days**.
- An assessment and, where the report is confirmed, a fix in a timely
  manner, coordinated with you on a disclosure timeline.
- Credit for the discovery in the release notes, unless you prefer to
  remain anonymous.

Thank you for helping keep `bote` and its users safe.
